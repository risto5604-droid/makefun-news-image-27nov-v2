A small Python program that sums up Friday 27 November 2026's world news in a single 1024×1024 image: six hero stories with hand-drawn pictograms, a stylised world map with numbered pins at each story's location, and a 30-item dated news list grouped by region. It uses only the Python standard library and Pillow, bundles its own DejaVu fonts, and renders byte-identical output on every run.

## Run it

```sh
python3 main.py
```
